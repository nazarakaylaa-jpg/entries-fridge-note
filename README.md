# Notes From a Passive-Aggressive Fridge

A make.fun bounty entry: one funny passive-aggressive note a smart fridge leaves for its owner — a single line, dry, petty and specific, the sort of thing a smug appliance would put on its door screen.

## The note

> You opened me 47 times today and took nothing. At this point I'm just a cold mirror.

## How it works

`main.ts` (Node 22) writes the note to `/output/entry.txt`:

```sh
node main.ts
```

The joke: the fridge logs every door-open like a petty clerk, then lands the sting — after 47 empty visits, it is no longer an appliance, just a cold mirror.
